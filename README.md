# Portfolio

Cloud and DevOps engineer portfolio. Plain HTML and CSS, hosted on GitHub Pages.

Files: `index.html` (home page), `day-1.html` (Linux Day 1 notes), `style.css` (shared styles).

## Publish on GitHub Pages
1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `day-1.html`, `style.css` and `README.md` (Add file > Upload files), then commit.
3. Open Settings > Pages. Under Build and deployment, set Source to Deploy from a branch, choose branch `main` and folder `/ (root)`, then Save.
4. Wait 1 to 2 minutes. Your site is at `https://YOUR-USERNAME.github.io/`.
